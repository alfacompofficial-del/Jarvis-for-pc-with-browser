# 🤖 Jarvis for PC

Умный голосовой AI-ассистент для Windows, вдохновлённый Jarvis из фильмов про Железного Человека.

## ✨ Возможности

- 🎤 **Голосовое управление** — скажите "Хей Джарвис" для активации
- 🧠 **AI на базе Groq** (llama-3.3-70b-versatile) — умные ответы на любые вопросы
- 💬 **Память диалогов** — помнит контекст разговора
- 🤖 **Анимированная аватарка** — реагирует на речь и команды
- 🌐 **Встроенный браузер** с AI-функциями (тёмная тема, перевод, режим чтения)
- 🗂️ **Вкладки** — чат, макросы, задачи
- 🖥️ **Системные команды** — открытие приложений, файлов, сайтов

## 🖥️ Требования

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Микрофон (для голосовых команд)
- Интернет (для AI ответов)

## 🚀 Запуск

```bash
# Клонировать репозиторий
git clone https://github.com/alfacompofficial-del/Jarvis-for-pc-with-browser.git
cd Jarvis-for-pc-with-browser

# Запустить
cd src/Jarvis
dotnet run
```

Или собрать и запустить EXE:
```bash
cd src/Jarvis
dotnet build
bin\Debug\net8.0-windows\Jarvis.exe
```

## 🎤 Голосовые команды

| Команда | Действие |
|---------|----------|
| "Хей Джарвис" | Активация |
| "открой ютуб" | Открыть YouTube |
| "открой telegram" | Запустить Telegram |
| "сделай скриншот" | Снимок экрана |
| "выключи компьютер" | Выключение ПК |
| "который час" | Текущее время |
| "погода" | Прогноз погоды |
| "найди [запрос]" | Поиск в Google |

## 🛠️ Стек технологий

- **C# / WPF** — основное приложение
- **.NET 8** — платформа
- **Groq API** (llama-3.3-70b) — искусственный интеллект
- **System.Speech** — распознавание и синтез речи
- **WebView2** — встроенный браузер
- **Newtonsoft.Json** — обработка JSON

## 🔑 API ключ

Jarvis использует Groq API. По умолчанию встроен ключ для демонстрации. Для личного использования замените в `MainWindow.xaml.cs`:

```csharp
private readonly string _groqKey = "ВАШ_КЛЮЧ_ЗДЕСЬ";
```

Получить ключ: [console.groq.com](https://console.groq.com)
